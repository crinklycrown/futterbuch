# Futterbuch

Ernährungstagebuch als Web-App (PWA) – läuft offline, alle Daten bleiben lokal auf dem Handy.

- Wochenansicht mit KW, Mahlzeiten (Frühstück, Mittag, Abendessen, Snacks)
- Lebensmittel-Datenbank (Richtwerte pro 100 g), eigene Lebensmittel, Gerichte/Rezepte
- Fotos pro Mahlzeit, Tagesexport zum Teilen, Backup als Datei

App öffnen: https://crinklycrown.github.io/futterbuch/
